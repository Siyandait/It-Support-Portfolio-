Active Directory User Management

Project Overview

This project focuses on learning how Active Directory manages users, groups, and computers in a Windows domain environment.

Lab Environment

* Server: Windows Server 2022
* Client: Windows 10
* Domain: banele.local

Tasks Practised

* Creating user accounts
* Creating and managing security groups
* Organising users with Organizational Units (OUs)
* Managing account properties
* Configuring user permissions
* Joining client computers to a domain

Troubleshooting

Common issues to investigate include:

* Incorrect DNS settings preventing domain discovery
* Domain join failures
* Incorrect usernames or passwords
* User account lockouts
* Permission problems

Learning Objectives

* Understand centralized user management.
* Learn how security groups help manage access.
* Understand how DNS supports Active Directory.
* Develop troubleshooting skills for Windows domain environments.

Results

I will document the tasks I complete, the problems encountered, and the solutions tested in my home lab.
